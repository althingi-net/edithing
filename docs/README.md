# Edithing Documentation

This directory contains Mermaid flow charts that visualize the architecture and data flow of different packages in the Edithing monorepo.

## Flow Charts

### Client Flow (`client-flow.mmd`)
Visualizes the React application structure, including:
- Component hierarchy
- Context providers
- Routing system
- Feature organization

### Server Flow (`server-flow.mmd`)
Shows the backend architecture, including:
- Request flow
- Controller organization
- Service layer
- External integrations

### Law Document Flow (`law-document-flow.mmd`)
Illustrates the document structure and processing:
- Document hierarchy
- Slate editor integration
- Processing pipeline

### Law Document Editor Flow (`law-document-editor-flow.mmd`)
Details the editor component architecture:
- Core editor components
- Document model
- Utility functions
- User interaction handling

### Git JSON Merger Flow (`git-json-merger-flow.mmd`)
Shows the JSON merging process:
- Git operations
- Merge strategies
- Conflict resolution
- Process flow

### Client SDK Flow (`client-sdk-flow.mmd`)
Visualizes the SDK architecture:
- Core functionality
- Service organization
- Data models
- API interactions

## How to View

These flow charts are written in Mermaid syntax and can be viewed using:
1. GitHub's built-in Mermaid support
2. Mermaid Live Editor (https://mermaid.live)
3. VS Code with Mermaid extension

## Contributing

When making changes to the codebase, please update the relevant flow charts to maintain accurate documentation.
